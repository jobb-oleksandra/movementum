# Movementum Retreat — endringer etter briefen (02.11.2026)

Denne arbeidsversjonen er bygget videre på `movementum(3).zip` med de sist avtalte parallax- og overlay-endringene. **Bare `retreat.html` og `css/retreat.css` er endret i denne runden.** `index.html`, `css/styles.css`, `js/retreat-parallax.js`, alle bilder og video er beholdt.

## Hva som er oppdatert

- Hero tydeliggjør dato, sted og retning, med separat lenke til programinnhold og til status for påmelding.
- Introduksjonen forklarer hvorfor kvinnekroppen, bevegelse og hverdagsbelastning er relevant for retreatet.
- De fire konseptområdene er skrevet tydeligere: faglig innsikt, bevegelse, fellesskap og velvære.
- Kvinnehelse-seksjonen utdyper foreløpige temaer uten medisinske løfter eller individuelle råd.
- «Kom som du er. Også alene.» og tilhørende bilde/oppsett er beholdt.
- Nora-seksjonen skiller bekreftet rolle som grunnlegger fra uavklart rolle under arrangementet.
- Programmet er inndelt i lørdag 16. og søndag 17. januar, **uten å finne på klokkeslett eller foredrag**.
- Praktisk informasjon skiller fakta fra åpne spørsmål om pris, overnatting, måltider, nivå, betingelser og fagpersoner.
- FAQ er mer nyttig; uriktige bildebeskrivelser er korrigert.
- Det er gjort en liten mobilretting av overlapping i videoens infolapp.

## Må avklares med Nora før publisering

1. Endelig program, klokkeslett, eventuelle treningsnivåer og spesialtilpasning.
2. Fagpersoner, foredragsholdere, navn og kvalifikasjoner samt Noras konkrete rolle under helgen.
3. Hva som inngår i prisen; overnatting, romtype/romdeling, måltider og lørdagsmiddag.
4. Pris, vilkår for kjøp, avbestilling og refusjon.
5. Ekte URL til påmelding eller fungerende interesse-/kontaktskjema, og hvor innsendte forespørsler skal sendes.
6. Endelig godkjenning av alle publiserte tekster og hva som faktisk skal inngå i arrangementet.

**Viktig:** Påmelding kan ikke sendes fra prototypen. Hero-knappen går til en ærlig statusseksjon, ikke til et ikke-fungerende skjema. Ingen booking-URL, e-postadresse, priser, programtider eller fagpersoner er funnet på.

Vennligst bruk `retreat.html` med VS Code Live Server for video og parallax. Designet bruker nettstedets eksisterende `css/styles.css`, og felles bildeformat og cropping er beholdt.
