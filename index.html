Når tanke møter bevegelse.

Movementum handler om å se hele mennesket. Ikke om å gjøre alt på én gang, men om å skape rom for det som gir mening over tid.

Mindset

Hvordan vi møter utfordringer, tenker og gir oss selv muligheten til å velge.

Movement

Bevegelse og aktivitet med plass til ulike forutsetninger og livssituasjoner.

Momentum

De små valgene vi gjentar, og retningen de kan skape over tid.

Hvordan kan vi bli mer nysgjerrige på kroppens behov gjennom ulike livsfaser? På retreatet ønsker vi å gi rom for spørsmål og samtaler om kvinnehelse.
