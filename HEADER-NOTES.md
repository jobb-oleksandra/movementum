# Header-oppdatering – Movementum (3. november 2026)

Begge sidene bruker samme nav: Hjem, Retreat, Om Movementum, Produkter, Møt Nora, Kontakt.

- `Hjem` → `index.html`
- `Retreat` → `retreat.html`
- `Om Movementum` → eksisterende `index.html#om`
- `Produkter` → eksisterende `index.html#arsplanlegger` med videre lenke til nettbutikken
- `Møt Nora` → eksisterende `retreat.html#nora` (det finnes ennå ingen Nora-seksjon på forsiden)
- `Kontakt` → `#kontakt` i footeren på gjeldende side.

VIKTIG: Briefen og prosjektfilene oppgir ingen verifisert e-post, telefon eller fungerende kontaktskjema. Kontaktseksjonen har derfor en tydelig midlertidig tekst. Før publisering må denne erstattes med godkjent kontaktinformasjon/lenke fra Nora.

Kun disse filene er endret fra `movementum(7).zip`: `index.html`, `retreat.html`. Nye filer: `css/header-navigation.css`, `js/header-navigation.js`. Annet innhold, bilder, retreat-effekter og videoer er uendret.
